# Type in the first tab, rename the notepad, add a tab, type in that one.
#
# Two regressions, both about where the keyboard is. The window used to open
# with nothing focused, so the editor a DAW had just opened swallowed
# everything typed: the first line here is typed without clicking anywhere, so
# it catches that. And after the notepad had been renamed, a tab created
# afterwards received no keystrokes at all, because the name field had taken
# the keyboard and nothing gave it back.
#
# The name is its own field, and what is typed into it lands nowhere else: the
# first tab still reads what was written before the rename.
#
# Coordinates are inside the window: the name sits mid-toolbar, and the tab
# strip's + button follows the last tab.
type:# Mix notes
type:{ENTER}levels are close
plugin:204,50
type:{END}{BS 40}Ghostlight
plugin:129,87
type:# Drum bus
type:{ENTER}glue comp 4-1

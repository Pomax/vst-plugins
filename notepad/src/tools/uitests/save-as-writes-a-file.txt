# Save As, through the real toolbar button and the real native dialog.
#
# The regression: the dialog was opened from inside the frame being drawn. A
# native dialog runs its own message loop, so the window's frame timer fired
# and egui was asked to lay out a frame while it was already laying one out.
# The plugin died on the spot — which this test sees as no state being written
# at all, because a dead plugin never reaches its shutdown.
#
# The path is typed into the dialog's name field, so it lands in the build
# cache rather than wherever the dialog happened to be pointing.
# Clear the target first: saving over a file that is already there brings up
# an "already exists" prompt, and the test would sit waiting for someone to
# answer it.
remove:%CACHE%\saved-by-ui-test.md
type:# Saved by a UI test
plugin:567,50
wait:2500
type:%CACHE%\saved-by-ui-test.md
type:{ENTER}
wait:2000

expect:file at %CACHE%\saved-by-ui-test.md contains # Saved by a UI test
expect:tabs is 1
expect:tab 0 is # Saved by a UI test

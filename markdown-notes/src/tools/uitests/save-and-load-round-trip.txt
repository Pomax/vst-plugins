# A whole file round trip, through the real buttons and the real dialogs:
# save, check the file in code, delete it, save again with Save As, check that
# in code, then open it back and check what came in.
#
# A native dialog runs its own message loop, so one opened from inside the
# frame being drawn leaves the frame timer firing into a layout that is already
# under way, and the plugin dies. A dead plugin never reaches its shutdown, so
# this test sees that as no state written at all.

# Save is Save As until the document has a path, so this is the first dialog.
# The file it wrote is checked in code the moment the dialog closes, and then
# deleted in code: the save is proven right here, and the name is free for the
# save below to write to a file that does not exist, as this one did.
remove:%CACHE%\round-trip.md
type:# Mix notes
type:{ENTER}levels are close
press:Save|501,76
wait:500
type:%CACHE%\round-trip.md
type:{ENTER}
wait:500
written:%CACHE%\round-trip.md|# Mix notes\n\nlevels are close
remove:%CACHE%\round-trip.md

# Now a second section, and Save As. The document has a path by now, which is
# what makes this a different action from the save above rather than the same
# one twice. The file is checked in code the same way: both sections, in order.
# The + button carries no word, and a lone glyph is not something text
# recognition reads reliably: it is clicked where the code puts it, and that
# the click landed is said by the two tabs read at the end.
plugin:129,87
type:# Drum bus
press:Save As|567,76
wait:500
type:%CACHE%\round-trip.md
type:{ENTER}
wait:500
written:%CACHE%\round-trip.md|# Mix notes\n\nlevels are close\n\n# Drum bus

# Change the document, so that opening the file back has something to undo:
# an open that silently did nothing would leave this mark, and the
# expectations below refuse it.
plugin:400,300
type: and then some
wait:500

# Open the file back. It replaces what is open, so the mark is gone and the
# document is exactly what the file holds.
press:Open|443,76
wait:500
type:%CACHE%\round-trip.md
type:{ENTER}
wait:500

cleanup:%CACHE%\round-trip.md

# Both tabs, read rather than typed into: the expectations below take the
# document the plugin wrote and cut it into sections here, so they say
# nothing about how many tabs the plugin made or which text each one holds.
# A load that put the whole file in one tab satisfies them. Reading each tab
# does not: the second tab has to show its own line and not the first tab's.
press:Mix notes|60,113
wait:500
showing:levels are close|140
press:Drum bus|170,113
wait:500
showing:Drum bus|140
hidden:levels are close|140

expect:sections is 2
expect:section 0 is # Mix notes\n\nlevels are close
expect:section 1 is # Drum bus

# The section strip and the file buttons, in one run: making sections, naming
# the note, Save, Save As, dragging sections into each of the three kinds of
# place one can be dropped (between two sections, in front of the first, after
# the last), and opening a file back.
#
# Every file is checked in code the moment its dialog closes, which is where
# each stage is proven: the state the plugin writes is written once, on the
# way out, and by then the file opened last has replaced everything.
#
# A native dialog runs its own message loop, so one opened from inside the
# frame being drawn leaves the frame timer firing into a layout that is already
# under way, and the plugin dies. A dead plugin never reaches its shutdown, so
# this test sees that as no state written at all.
#
# The order after all three drags is `Vocal chain`, `Drum bus`, `Mix notes`,
# and nothing else produces that order. Fail any one drag and the result is
# different every time:
#
#   the first fails  -> Drum bus, Vocal chain, Mix notes
#   the second fails -> Mix notes, Drum bus, Vocal chain
#   the third fails  -> Vocal chain, Mix notes, Drum bus
#
# Two things about the keyboard are settled in the first few steps. Nothing is
# clicked before the first line is typed: a note nobody has named opens with
# the keyboard in its name, Enter sends it to the document, and the line lands
# there. Then the note is renamed and another section is made and typed into,
# which says the name field hands the keyboard back.
#
# The name sits mid-toolbar and is its own field: what is typed into it lands
# nowhere else, which the first section's text at the end says. The + button
# follows the last section, so it moves right as sections are added.
# Every section starts as a heading waiting for its name, with the name
# selected. Each one is read off the window before anything is typed, and the
# name typed straight after has to have replaced it: still showing afterwards
# means the selection was not there.
remove:%CACHE%\round-trip.md
remove:%CACHE%\dragged.md
type:{ENTER}
showing:Section Title|140
type:Mix notes
showing:Mix notes|140
hidden:Section Title|140
type:{ENTER}levels are close

# Save is Save As until the document has a path, so this is the first dialog.
# The file it wrote is checked in code, and then deleted in code: the name is
# free for the Save As below to write to a file that does not exist, as this
# one did.
press:Save|501,76
dialog:Save
type:%CACHE%\round-trip.md
type:{ENTER}
nodialog:Save
written:%CACHE%\round-trip.md|# Mix notes\n\nlevels are close
remove:%CACHE%\round-trip.md

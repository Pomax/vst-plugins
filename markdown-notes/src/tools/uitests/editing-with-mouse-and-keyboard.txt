# Editing the document with the pointer and the keyboard, through the real
# window: the pointer's shape over it, clicking past the end of a line,
# selecting by dragging, and the clipboard shortcuts.
#
# One run. The plugin writes its state once, on the way out, so the text at the
# end is what says whether each step did its job: every step leaves a mark the
# next one cannot produce on its own.
#
# An I-beam is how a window says "there is text here to put a caret in", so it
# is shown where a click would put one: over a line. The empty space below the
# last line takes the caret away instead of placing it, and the toolbar is not
# the document at all.
type:text goes here
cursor:60,155|ibeam
cursor:400,400|arrow
cursor:450,76|arrow

# Dragging through the text selects what it crosses, which typing then
# replaces. The press has to land inside the text: a line is only as wide as
# what is written on it, and a press beside it belongs to no line at all.
# The drag runs from where "goes here" starts, found by looking rather than
# by a pixel count, to past the end of the line, so what it selects is
# everything from there on: "text goes here" becomes "text X". The end of the
# drag sits far right of the text so it is past the line's end whatever width
# a platform's font gives it. A word rather than part of one: text
# recognition places words, and a mark inside one snaps to its start.
dragtext:goes here|140|300,155
type:X
shot:%CACHE%\editing-dragged-to-select.png

# Clicking far to the right of a line puts the caret at the end of that line,
# not nowhere: the empty space to the right of a line belongs to it. A second
# line first, so the click has a short line above a long one to land beside.
type:{ENTER}second line
click:600,155
type:!

# Select the lot, cut it, and paste it back after some new text: the shortcuts
# have to reach the document for any of that to happen. This is the only test
# that presses Ctrl for real; the scenarios reach the editor through the
# plugin's own key entry point and never touch the window's keyboard.
shortcut:ctrl+a
shortcut:ctrl+x
wait:500
type:kept:
shortcut:ctrl+v
wait:500
shot:%CACHE%\editing-pasted.png

expect:sections is 1
expect:section 0 is kept:text X!\n\nsecond line

Answer over everything the question covers, not the part currently in mind.
"How many are there" means all of them. "Are the others still there" means all
the others, not the two left over from what I was just doing.

**Why:** a partial answer reads as a complete one. Listing three memory files
when there were eighteen was not brevity, it was wrong, and it looked like
files had appeared out of nowhere when the rest turned up a question later.

**How to apply:** before answering a question about a set — files, tests,
failures, changes — go and count the set. Say the total, then the part that is
relevant, and say which is which. Scoping to "the ones I touched" is only an
answer when that is what was asked. Related: [[plain-language]].

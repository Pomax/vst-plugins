# The plugin's window fills the host's, at whatever size the host is.
#
# The plugin is a window of its own inside the host's, and the host used to put
# it right on the next frame of its own drawing loop. That is a frame late for
# every frame of a drag: the host paints its new shape while the plugin still
# has the old one, so the edge of the window shows the host's background where
# the plugin has not caught up. Now the plugin's window is moved from inside
# the resize itself, so no size the host is ever set to can leave the two
# disagreeing.
#
# The strip across the top is 26 points tall, so the plugin gets everything
# below that: the same width, and the height less 26.
type:something to keep

remove:%CACHE%\host-resize.txt
resize:1000,700
wait:800
geometry:%CACHE%\host-resize.txt
shot:%CACHE%\host-resize-wide.png

# Smaller as well as bigger: a window that only ever grows can hide the case
# where the plugin is left overhanging the frame it is in.
remove:%CACHE%\host-resize-small.txt
resize:620,420
wait:800
geometry:%CACHE%\host-resize-small.txt

# And the way it actually happens: a hand on the corner, moving. Setting the
# size in one jump asks the window to go straight from one size to another,
# which is not the path that was ever broken. This films the drag, so what the
# window did while it was happening can be watched rather than guessed at.
remove:%CACHE%\host-resize-drag.txt
# Filmed over a region big enough for the size the window is dragged to, since
# the region is fixed once recording starts: the part of the screen the window
# grows into is exactly the part worth watching.
film:%CACHE%\host-resize-drag|920,640
dragedge:260,180,1000
endfilm:
wait:800
geometry:%CACHE%\host-resize-dragged.txt

expect:file at %CACHE%\host-resize.txt contains host=1000x700
expect:file at %CACHE%\host-resize.txt contains editor=0,26,1000x674
expect:file at %CACHE%\host-resize-small.txt contains host=620x420
expect:file at %CACHE%\host-resize-small.txt contains editor=0,26,620x394
# The corner was dragged 260 right and 180 down from 620x420, so the window is
# 880x600 afterwards. Named exactly, because a grab that lands on the wrong
# pixel and drags nothing leaves the window as it was, and a test that only
# asked whether the plugin still fits would pass on that.
expect:file at %CACHE%\host-resize-dragged.txt contains host=880x600
# And the plugin fills it: nothing above it but the strip, nothing beside or
# below it at all.
expect:file at %CACHE%\host-resize-dragged.txt contains inset=0,26,0,0
# And the plugin is still alive and still taking keys after all of that.
expect:sections is 1
expect:section 0 is something to keep

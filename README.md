# VST Plugins

This is a repository of proof-of-concept VST3 plugins that I needed and couldn't find a decent free or paid version for already, and so used text predictors to generate instead.

## Plugins

There is currently one plugin here, aimed at letting you put your project document(s) directly in your project as multi-tabbed markdown, with image as well as flow and gannt chart support.

[Read me about that here](./markdown-notes/README.md)
